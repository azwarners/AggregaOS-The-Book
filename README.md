# AggregaOS: The Book

This repository contains the source manuscript and supporting notes for *AggregaOS: The Book*.

The book is autobiographical in nature. It traces the author's history with computers, productivity, Linux, software development, AI-assisted software production, and the sequence of projects and design decisions that eventually led to AggregaOS.

## Authorship

The manuscript is written entirely by Nick Warner.

Generative AI is not used to write the prose of the book. AI tools may be used for research, fact-checking, proofreading, critique, organization, historical reconstruction, and discussion, but the manuscript itself is human-authored.

## Repository structure

- `manuscript/` — the book itself
- `notes/` — timelines, project archaeology, memories, chapter ideas, and other working notes
- `research/` — references, links, source material, and factual research
- `images/` — images and other visual material intended for or related to the book
